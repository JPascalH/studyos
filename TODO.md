# StudyOS – Umsetzungsliste

- [x] **Fokus-Timer:** StudyOS bietet einen Fokus-Timer mit Lern- und Pausenmodus.
- [x] **Aufgabenliste:** StudyOS bietet eine Aufgabenliste mit Fach, Abgabetermin und Erledigt-Status.
- [x] **Schnellnotizen und Offline-Daten:** Schnellnotizen werden lokal im Browser gespeichert und sind offline verfügbar.
- [x] **Lernfortschritt:** StudyOS zeigt den Lernfortschritt mit Tages-Serie und einem übersichtlichen Fortschrittsbalken.
- [x] **Online-Lernsuche:** Mit Internetverbindung kann man Lernbegriffe suchen und kurze Wikipedia-Zusammenfassungen mit Quellenlinks ansehen.
- [x] **Visuelles Konzept und Gerätekomfort:** StudyOS ist ein leichtes, responsives Lern-Cockpit für den Laptop mit dunkler, cooler Gaming-/Cyberpunk-inspirierter Gestaltung.
- [x] **Installierbare PWA:** StudyOS besitzt ein eigenes Manifest, passende 192×192- und 512×512-PNG-App-Symbole sowie einen Service Worker, der die App-Shell und Symbole nach dem ersten erfolgreichen Laden für Offline-Zugriff zwischenspeichert.
- [x] **Passwortloser Daten-Transfer:** Im Bereich „Daten“ kann man Aufgaben, Notizen, Lernserie, Fokus-Sessions und Timerstand als JSON-Datei herunterladen und auf einem anderen Laptop importieren. Es wird kein E-Mail-/Passwortkonto und keine Cloud-Synchronisierung benötigt; ein Import überschreibt nach Bestätigung die lokalen App-Daten.
- [x] **Name und Tageszeit-Begrüßung:** Im Profilmenü kann ein Name eingegeben werden. StudyOS begrüßt mit dem Namen und passt die Begrüßung an die Tageszeit an, zum Beispiel „Guten Morgen“ am Morgen. Name und Sprache werden lokal gespeichert und in der JSON-Sicherung mitübertragen.
- [x] **Deutsch/Englisch:** Die Oberfläche kann auf Deutsch oder Englisch umgeschaltet werden; die Lernsuche verwendet die jeweils passende Wikipedia-Sprache.
- [x] **Verbindung und Updates:** StudyOS zeigt den Online-/Offline-Status. Wenn eine neue Service-Worker-Version bereitsteht, erscheint ein Update-Hinweis mit Möglichkeit zur sofortigen Aktualisierung.
- [x] **Desktop-Installation:** Ein Installieren-Knopf startet, sofern der Browser es anbietet, die PWA-Installation; andernfalls erklärt er, wie die App über Edge oder Chrome installiert werden kann.
- [ ] **Echter Windows-EXE-Installer:** Noch nicht erstellt. Die derzeitige Desktop-Installation ist eine PWA-Installation und keine herunterladbare eigenständige `.exe`-Datei.
