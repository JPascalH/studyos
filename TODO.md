# StudyOS – Umsetzungsliste

- [x] **Fokus-Timer:** StudyOS bietet einen Fokus-Timer mit Lern- und Pausenmodus.
- [x] **Aufgabenliste:** StudyOS bietet eine Aufgabenliste mit Fach, Abgabetermin und Erledigt-Status.
- [x] **Schnellnotizen und Offline-Daten:** Schnellnotizen werden lokal im Browser gespeichert und sind offline verfügbar.
- [x] **Lernfortschritt:** StudyOS zeigt den Lernfortschritt mit Tages-Serie und einem übersichtlichen Fortschrittsbalken.
- [x] **Online-Lernsuche:** Mit Internetverbindung kann man Lernbegriffe suchen und kurze Wikipedia-Zusammenfassungen mit Quellenlinks ansehen.
- [x] **Visuelles Konzept und Gerätekomfort:** StudyOS ist ein leichtes, responsives Lern-Cockpit für den Laptop mit dunkler, cooler Gaming-/Cyberpunk-inspirierter Gestaltung.
